## Браузер

Проверка во встроенном браузере, целевое окно 1366×768 и мобильный viewport 390×844. Сервер `tests/serve-fixtures.mjs` использует только искусственные записи и явно сообщает об этом в UI.

- Без backend: понятная ошибка и повтор запроса, отсутствуют вымышленные значения.
- `0007` через Enter сохраняет ведущие нули, открывает направленный граф и карточку.
- Клик по вершине открывает `0012`; строка списка открывает `0042`.
- У `0042` видны нулевые исходящие, нулевой role_score, неизвестные флаги и ограничение обхода; insufficient_evidence объяснён явно.
- Неизвестный gid очищает предыдущие карточку, граф и AI-панель.
- `0999` открывает один узел без рёбер.
- Компонента `fixture-large` показывает 300 из 320 узлов, ограничение видно. Поиск `L0001` после большой компоненты работает; радиус 1/2 меняет выдачу с 2 до 3 узлов.
- Кластер открывает формальную гипотезу и список участников. Выбор из доступного с клавиатуры списка графа открывает ту же карточку `0007`.
- Explain и investigate показывают явный fallback, основания, выполненные проверки и ограничения. Внешний провайдер не вызывался.
- На мобильном viewport горизонтального переполнения нет: ширина контента совпадает с шириной documentElement.
- После удаления настройки wheelSensitivity ошибок и предупреждений в новой странице проверки не обнаружено.
- CSV endpoint вернул HTTP 200, Content-Disposition `roles.csv`, правильный заголовок и 324 записи. Меню выгрузок отправляет запрос без UI-ошибки. Событие download встроенный браузер не подтвердил; сохранение файла на диск и все экспорты остаются пунктом проверки с настоящим FastAPI B.
