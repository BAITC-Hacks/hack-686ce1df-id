# Исправления по ревью — 23 сентября 2026

Исправлены все семь замечаний к фронтенду и связанным API.

1. Источник данных читается из `X-Data-Source` ответа health. Обычная production-сборка показывает предупреждение при `--fixtures`; явный `artifacts` имеет приоритет над переменной fixture-сборки.
2. При смене радиуса для прежнего объекта сохраняются AI-ответ, черновик и выполняющийся запрос. Повторное нажатие активного радиуса не отправляет запрос. Смена объекта или расчёта по-прежнему очищает AI и отменяет устаревшие запросы.
3. Backend предоставляет восемь стабильных имён выгрузок, включая исходные байты `manifest.json`. Логические имена работают и при ключах с расширениями в `manifest.files`; явно перечисленные дополнительные экспорты сохраняются.
4. Панель графа прокручивается независимо, поэтому клавиатурный выбор остаётся доступным на невысоком экране.
5. Под графом есть доступная таблица направленных связей: отправитель, получатель, точная сумма и количество переводов. Пагинация ограничивает DOM 25 строками; концы связи можно выбрать кнопками.
6. Карточки используют query-маршруты `/api/node?gid=…` и `/api/cluster?cluster_id=…`, сохраняющие `/`, Unicode, точки и другие специальные символы. Старые пути API сохранены и поддерживают идентификаторы со слешами.
7. Cytoscape загружается динамически после появления узлов. При ошибке загрузки доступны повтор и текстовое представление графа.

- Предупреждение об искусственных данных появляется без `VITE_DATA_SOURCE=fixture`.
- Выбор `0007`, получение локального AI-ответа и переход с радиуса 1 на 2 сохраняют ответ и черновик вопроса.

- Графовый JS запрашивается после первого выбора узла, а не при загрузке пустого пространства.
- При 1024×600 клавиатурный фокус переводится в видимый список узлов; панель прокручивается, нижняя панель его не перекрывает.

Проверки использовали искусственные данные и локальный AI-fallback. Настоящие входные данные, платный AI-провайдер и производительность полного аналитического расчёта не проверялись.
