## Запуск

Из корня проекта после установки `requirements.lock` и сборки frontend:

```sh
.venv/bin/python -m backend --data-dir data/raw --port 8003
```

Приложение: http://127.0.0.1:8003. Порты 8000 и 8002 были заняты другими
локальными процессами; они не останавливались. Для выполненной проверки
`OPENAI_API_KEY` и `AI_MODEL` заданы пустыми в окружении серверного процесса.
Внешняя модель не вызывалась; объяснения используют локальный fallback.

Только пересчёт и отдельная проверка работающего HTTP-сервера:

```sh
.venv/bin/python -m backend.app.analytics.cli run --input-dir data/raw --output-dir artifacts --rules config/rules.json --mapping config/input_mapping.json
.venv/bin/python scripts/real_smoke.py --base-url http://127.0.0.1:8003
```

## Границы результата

Роли и приоритет — детерминированные инженерные гипотезы по
`config/rules.json`, не оценка виновности и не обученная модель.
Период, фильтр суммы и исходящий обход ограничивают выводы.
97 одинаковых строк переводов сохранены: без id транзакции нельзя
утверждать, что это дубли. Временные признаки описывают календарную
активность и не доказывают прохождение тех же средств.

Живой внешний AI, качество классификации по независимой разметке и
масштаб до миллиона узлов здесь не проверялись. Обязательные результаты
и локальное приложение работают без этих внешних зависимостей.
