# «Граф денег»: комплект для сдачи

В комплекте находится решение на предоставленном графе внутрибанковских
переводов за июль 2026: **2248 узлов, 3119 направленных пар, 4840 переводов**.
Результат расчёта — `real-693e46ac2fdb69419d42968f`.

## Состав архива

- `results/nodes_roles.csv` — 2248 строк, все 15 колонок starter и статус
  назначения роли. gid следует импортировать как текст, не как число Excel.
- `results/clusters.csv` — 106 кластеров с численными характеристиками и
  гипотезами назначения.
- `results/top_nodes.csv` — 20 узлов в порядке убывания приоритета.
- `artifacts/real-693e46ac2fdb69419d42968f/` — полный неизменяемый расчёт:
  JSON, CSV, правила, mapping, аудит, временные признаки и паспорт запуска.
- `source/` — исходный код, lock-файлы, Docker и документация.
- `verification.json` — протокол проверки CSV, воспроизводимости и Docker.
- `package-metadata.json` — идентификатор расчёта и версия исходного кода.
- `SHA256SUMS` — контрольные суммы файлов комплекта.

Исходные Parquet и API-ключи не включены. Результаты содержат идентификаторы
и агрегаты предоставленного набора. Архив создан локально; автоматической
публикации или отправки организаторам не выполнялось.

## Просмотр готового результата

Нужен Docker Desktop с Linux-контейнерами либо Docker Engine с Compose.
После распаковки перейти в `source/`. Если `.env` ещё нет, создать его
по образцу `.env.example`. В локальном `.env` задать:

```dotenv
APP_PORT=8000
AML_ARTIFACTS_DIR=../artifacts/real-693e46ac2fdb69419d42968f
```

Запустить из `source/`:

```sh
docker compose -f compose.yaml -f compose.artifacts.yaml up --build --wait --wait-timeout 90
```

Открыть `http://localhost:8000`. Этот режим читает включённый готовый результат;
он не требует исходных Parquet. Первая сборка требует интернета для образов и
зависимостей; приложение и локальные объяснения затем работают без AI-провайдера.

Проверить готовое приложение:

```sh
docker compose -f compose.yaml -f compose.artifacts.yaml exec -T app python scripts/real_smoke.py --base-url http://127.0.0.1:8000
docker compose -f compose.yaml -f compose.artifacts.yaml exec -T app python scripts/verify_task_exports.py /app/artifacts/run
```

## Независимый пересчёт

Для воспроизведения расчёта разместить предоставленные организаторами
`nodes.parquet`, `edges.parquet`, `transactions.parquet` в `source/data/raw/`.
Из `source/` выполнить:

```sh
docker compose -f compose.yaml -f compose.real.yaml up --build --wait --wait-timeout 90
```

Данные подключаются только для чтения; результаты сохраняются в отдельном
Docker volume. Пустой или некорректный вход останавливает запуск с ошибкой.
Включение фикстур не используется как запасной вариант.

Полный локальный расчёт проверен дважды: 1,83 и 1,72 секунды на Apple M4.
Независимый повтор внутри Docker занял 2,62 секунды. Все 13 содержательных
артефактов совпали побайтно; времена внутри manifest закономерно различаются.
На другой машине время зависит от оборудования. Run ID включает версии
зависимостей и код расчёта, поэтому при смене среды он может измениться.

## AI

В `.env` можно задать свои `OPENAI_API_KEY` и `AI_MODEL`, затем повторить `up`
с теми же Compose-файлами. Ключ не записывать в `.env.example` или исходники.
Без настроек доступны локальные объяснения; обязательные CSV и граф работают
независимо от AI. При использовании внешнего AI ему передаются необходимые
поля выбранной карточки и результатов разрешённых проверок.

Пользователь подтвердил работу живого AI. Автоматические проверки не вызывали
внешнего провайдера; статус fallback в интерфейсе не следует представлять как
ответ модели. Подробности и ограничения: `source/docs/ai.md`.

## Как трактовать результат

Роли и score — воспроизводимые гипотезы по явным правилам, не вероятность
нарушения и не обученная модель. Оценки CSV лежат в диапазоне 0–1; в приложении
они показаны в шкале 0–100. `NA` в `pass_through` означает неопределённое O/I
при нулевом входе; это не ноль. У 42 узлов отношение не определено.

444 узла на границе обхода не объявляются конечными получателями только из-за
отсутствия исходящих. Входящие у seed наблюдаются неполно. Период, порог суммы
и направление обхода ограничивают интерпретацию. PageRank учитывает направление
и суммы; Louvain использует явно описанную неориентированную проекцию.

Формулы и пороги: `source/docs/methodology.md`. Протокол проверок:
`source/docs/real-data-verification.md`. Текущий полный backend-прогон —
548 тестов и сверка OpenAPI; frontend не менялся после 70 прошедших тестов
и production-сборки. GitHub Actions при предыдущем PR был недоступен из-за
billing-блокировки аккаунта; локальные проверки не называются удалённым CI.

Для защиты подготовьте объяснение конкретного gid с численными основаниями,
пример границы обхода и изолят. Не заявляйте доказанное назначение клиента
или прохождение тех же средств: исходные данные этого не устанавливают.
Готовый сценарий на 3–5 минут: `source/docs/demo-script.md`.
