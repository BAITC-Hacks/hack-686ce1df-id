# Реальные данные: завершение аналитического расчёта

**Goal:** Выполнить поручение «сделай дальше с кодом всё что требуется»: из предоставленных Parquet получить проверенные роли, кластеры, приоритеты, CSV задания и работающий интерфейс.

**Architecture:** Продолжаем существующую согласованную архитектуру, без замены приложения. Строгий вход → детерминированные правила и Louvain → неизменяемые артефакты контракта v1 → существующий FastAPI и React. Отдельный экспорт переводит внутренние score 0–100 в шкалу 0–1 из starter.

**Tech Stack:** Python 3.12, PyArrow, NetworkX, Pydantic/FastAPI, React/TypeScript.

**Spec:** `docs/superpowers/specs/2026-09-23-money-graph-design.md`, `docs/contracts/money-graph-v1.md`, `docs/data-intake-2026-09-23.md`; предоставленный `data/reference/starter/starter.py` определяет CSV сдачи.

## Решения и ограничения

- Исходные файлы не изменяются; данные и артефакты остаются локально и исключены из Git.
- Денежные float принимаются только по явно заданной политике Decimal(str(value)), без округления, с проверкой конечности, диапазона точности и двух десятичных знаков. Дальнейшие суммы — целые тиыны.
- Сопоставление фиксирует исходящий обход глубины 4. Граница обхода помечается; полнота входящих извне выборки не заявляется ни для одного узла.
- Роли — гипотезы наблюдаемого графа. Балансовые правила не применяются к seed или обрезанным узлам; terminal запрещён при неизвестной или обрезанной исходящей наблюдаемости.
- Правила используют явные пороги из методологии, детерминированный порядок конфликтов и остаточный peripheral/insufficient_evidence. Конфигурация — инженерная версия для кейса, не статистически валидированная модель риска.
- Кластеры Louvain внутри слабосвязных компонент, сумма количеств переводов в неориентированной проекции, seed 42. Все изоляты сохраняются.
- Каждая роль и приоритет имеют фактические численные основания; данные времени используются для дополнительных наблюдаемых признаков без утверждения о движении тех же денег.
- Существующие несохранённые изменения демо сохраняются. Публикация и платные внешние вызовы не входят в эту работу.
