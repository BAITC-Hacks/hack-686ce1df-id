# B — Backend, контракт и интеграция

**Goal:** Дать frontend и AI один согласованный API, подключить настоящие результаты и обеспечить воспроизводимый запуск команды.

**Architecture / Tech Stack:** один FastAPI-процесс, Pydantic-модели, локальный ResultStore в памяти из законченного набора файлов.

**Spec:** [архитектура](../specs/2026-09-23-money-graph-design.md), [контракт](../../contracts/money-graph-v1.md), [общий план и ограничения](2026-09-23-money-graph-parallel.md).

**Фактический статус 23.09.2026:** самостоятельная часть B реализована и проверена на явных искусственных фикстурах: модели, OpenAPI, ResultStore, HTTP API, экспорт снимка, граница AI с локальной справкой, конфигурация, раздача статической сборки и README. 102 API-теста проходят также в чистом окружении из `requirements.lock`. Контракт JSON v1 сохранён; источник отмечен заголовком `X-Data-Source`. Настоящие артефакты A, сборка C и сервис D ещё не получены; совместные пункты и полный пересчёт не считаются выполненными.

## Владение и интерфейсы

Создать `backend/app/contracts.py`, `backend/app/store.py`, `backend/app/main.py`, `backend/app/api/{nodes,graph,clusters,exports,ai}.py`, `tests/api/`, `contracts/openapi.json`, `tests/fixtures/contract-v1/`. Владеть общими Python-зависимостями, конфигурацией запуска, `.gitignore`, `.env.example`, README.

`ResultStore` предоставляет:

```python
get_node(gid: str) -> NodeRecord
get_neighbors(gid: str, radius: int = 1, limit: int = 50) -> GraphResponse
get_cluster(cluster_id: str) -> ClusterRecord
check_concentration(gid: str) -> dict
```

Последний метод вызывает функцию A на текущих edges. Не дублировать формулу в API и AI. `GraphResponse` — точный объект GET /api/graph из контракта. `ExplainRequest`, `InvestigateRequest` и `AIResponse` — Pydantic-модели соответствующих тел из контракта. D реализует async-функции `explain(request, store)` и `investigate(request, store)` и возвращает AIResponse.

```python

    response = client.get('/api/nodes/0007')
    assert response.status_code == 200
    assert response.json()['node']['gid'] == '0007'

    response = client.get('/api/nodes/not-in-fixture')
    assert response.status_code == 404
    assert 'message' in response.json()['error']
```
